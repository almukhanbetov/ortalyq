# Сценарий демонстрации (5–7 минут, два устройства)

**Подготовка:** `docker compose exec backend server seed` (или только `server demo-room`, чтобы пересоздать чистый демо-класс). Демо-класс открыт сразу и в любое время. Ноутбук — **преподаватель** (`teacher@demo.ortalyq.local`), телефон или второй компьютер — **ученик** (`student@demo.ortalyq.local`). Пароль — `DEMO_PASSWORD`. На телефоне заранее откройте `https://<IP>:8443` и примите сертификат.

| Время | Устройство | Действие | Что сказать |
|---|---|---|---|
| 0:00 | Ученик | Главная → «Преподаватели», фильтр «Математика», цена до 6 000 ₸ | Каталог с фильтрами по предмету и цене, рейтинг из отзывов |
| 0:40 | Ученик | фильтр «Алматы» → карточка «Айгерим Нурланова» → выбрать день и время → «Записаться» | Слоты в часовом поясе ученика, занятое время скрыто, двойная запись невозможна |
| 1:20 | Ученик | «Объявления» → фильтр «Заявки учеников» → «+ Найти преподавателя» | Доска объявлений: свои можно редактировать и удалять, администратор может скрыть |
| 1:50 | Оба | «Кабинет» → блок «Виртуальный класс открыт» (или раздел «Мои занятия») → «🎥 Войти в класс» | Обычные занятия открываются за 15 минут до начала, демо-класс — всегда |
| 2:10 | Оба | Проверка камеры и микрофона → «Войти в класс» | Индикатор громкости, выбор устройств, понятные ошибки доступа |
| 2:40 | Оба | Поговорить, выключить и включить микрофон и камеру | Видео и звук в обе стороны, состояние «ожидание участника» |
| 3:10 | Преподаватель + ученик | Нарисовать на доске (прямоугольник, текст, ластик); ученик дорисовывает | Общая доска синхронизируется у обоих |
| 3:50 | Преподаватель | «Экран» — показать вкладку или окно | Демонстрация экрана (на телефоне функция недоступна — это ограничение мобильных браузеров) |
| 4:10 | Преподаватель | «⏺ Начать запись» → подтверждение; ученик → «Согласен на запись» | Без согласия обоих запись не начнётся. Красный индикатор «Идёт запись» у обоих |
| 4:50 | Оба | Сообщение в чате; ученик обновляет страницу | После переподключения доска и чат восстанавливаются |
| 5:20 | Преподаватель | «Остановить запись» → «Завершить занятие» | У ученика появляется «Занятие завершено» |
| 5:40 | Преподаватель | Страница занятия → «+ Задать» домашнее задание (с файлом) | Материалы и задания привязаны к уроку |
| 6:00 | Ученик | Страница занятия: «Смотреть» запись, «Открыть» доску, ответить на ДЗ, оставить отзыв | Запись закрытая, ссылка временная; доска сохранена |
| 6:30 | Преподаватель | Комментарий к ответу → «Отметить проверенной» | Полный цикл ДЗ: назначение → ответ → проверка |

**Если спросят о безопасности:** войдите как `student2@demo.ortalyq.local` и откройте ссылку на чужое занятие — откроется «Не удалось открыть класс» (сервер возвращает 404).

**Если запись готовится дольше минуты:** обновите страницу занятия. Статус меняется «Обрабатывается» → «Готова».
