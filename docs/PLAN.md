# План MVP ORTALYQ

Репозиторий был пуст, поэтому выбран стек по умолчанию: **Go + Gin**, **PostgreSQL**, **Next.js + TypeScript**.

| Область | Решение |
|---|---|
| Авторизация | Регистрация (ученик/преподаватель), argon2id для паролей, серверные сессии (случайный токен, в БД хранится SHA-256), HttpOnly-cookie, проверка `Origin` для изменяющих запросов. Администратор создаётся только CLI-командой. |
| Права | Каждый обработчик проверяет роль и участие в занятии на сервере. |
| Расписание | Преподаватель задаёт окна доступности; ученик выбирает начало внутри окна. Двойное бронирование исключено ограничением `EXCLUDE USING gist` по `tstzrange` (для преподавателя и ученика), поэтому одновременные запросы тоже защищены. Время хранится в UTC (`timestamptz`). |
| Видео | LiveKit (self-hosted в docker compose или LiveKit Cloud). Токен выдаёт бэкенд только участникам занятия во временном окне. |
| Чат и доска | Собственный WebSocket бэкенда на каждое занятие: чат сохраняется в БД, доска (Excalidraw) синхронизируется поэлементно с версиями и сохраняется в БД; после переподключения клиент получает актуальное состояние. |
| Запись | LiveKit Egress: RoomComposite с собственным шаблоном `/recorder/...`, который рисует доску, демонстрацию экрана, видео и звук участников. Файл MP4 загружается Egress прямо в закрытый S3 (MinIO). Согласие обоих участников обязательно до старта. |
| Файлы | S3-совместимое хранилище (MinIO), закрытый бакет. Скачивание через временные подписанные ссылки бэкенда (HMAC, срок жизни 10 минут), которые выдаются только после проверки прав. |
| Домашние задания | Задание → ответ (текст/файл) → комментарий и статус «проверено». |
| Демо | Команда `seed` создаёт вымышленные данные с пометкой «ДЕМО». |
| Доступ с телефона | Caddy с HTTPS (внутренний CA) как единая точка входа: `/api` → Go, `/rtc` → LiveKit, остальное → Next.js. |
