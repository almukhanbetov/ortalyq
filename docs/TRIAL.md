# Бесплатный ознакомительный урок

Преподаватель начинает урок в любой момент, без записи в расписании, и приглашает ученика ссылкой. Урок проходит в обычном виртуальном классе и завершается кнопкой преподавателя.

## Сценарий

1. Преподаватель (вошедший в аккаунт) нажимает **«Начать ознакомительный урок»** в кабинете или в «Моих занятиях». Урок создаётся и сразу открывается класс.
2. В классе и на странице урока преподаватель видит ссылку-приглашение `/trial/<id>#<код>` и кнопку «Копировать».
3. Ученик открывает ссылку. Если он не вошёл — «Войти» или «Зарегистрироваться», после чего возвращается к приглашению. Кнопка **«Присоединиться к уроку»** закрепляет его в уроке и открывает класс.
4. Класс тот же, что у обычного урока: видео (LiveKit), доска, чат, совместный код, учебная мастерская, запись с согласия обоих — с теми же правами преподавателя и ученика.
5. Преподаватель нажимает **«Завершить занятие»**: класс закрывается у обоих, запись останавливается, комната LiveKit удаляется. Доска, чат, материалы, задания и записи остаются на странице урока по правилам обычного урока.

Везде урок помечен **«Бесплатный ознакомительный урок»**, стоимость — «Бесплатно».

## Как устроено

Это обычная запись `lessons` (миграция `0009_trial_lesson.sql`):

| Поле | Значение |
|---|---|
| `is_trial` | `true` |
| `always_open` | `true` — вход определяется статусом урока, а не временем (существующий механизм) |
| `status` | `live` сразу при создании → `completed` по кнопке |
| `started_at` / `ended_at` | фактические начало и окончание |
| `starts_at` / `ends_at` | `ends_at` — заглушка (+1 с), при завершении — фактическое окончание |
| `price` | `0` (проверка БД `lessons_trial_free`) |
| `student_id` | пусто, пока ученик не присоединился (проверка `lessons_student_required` разрешает это только ознакомительному уроку) |

- **Доступ** — существующий `lessonAccess`: только преподаватель и присоединившийся ученик, посторонним 404. Вход в класс, видео, WebSocket и запуск кода — существующий `classProblem`: урок завершён → вход закрыт.
- **Приглашение** — код HMAC(`APP_SECRET`) от id урока. Он даёт только право занять единственное место ученика, пока урок идёт. Место занимается атомарно (`UPDATE … WHERE student_id IS NULL`): повторно тот же ученик — без изменений, второй — «уже присоединился другой ученик», после завершения — «урок уже завершён». Присоединиться может только аккаунт с ролью «ученик». Код передаётся во фрагменте адреса — не попадает в журналы сервера. Проверки кода ограничены: 30 попыток за 10 минут с адреса.
- **Без дубликатов.** Пока у преподавателя идёт ознакомительный урок или обычный урок в своё время, новый не создаётся: ответ 409 с id идущего урока, интерфейс предлагает «Открыть идущий урок». Одновременные нажатия защищены уникальным индексом `lessons_one_active_trial`.
- **Возврат после перезагрузки** — урок в «Предстоящих» и в блоке «Виртуальный класс открыт», адрес класса тот же.
- **Расписание и оплата.** Ознакомительный урок не занимает интервалы: `NOT is_trial` в запросах занятости (запись, свободные слоты, расписание преподавателя, диагностика) и в ограничениях `lessons_*_no_overlap`. Платежей в проекте нет; цена урока 0. Правила времени обычных уроков не менялись.
- **Фоновые задачи** не завершают и не отменяют урок (`always_open`): он идёт, пока преподаватель его не завершит.

## Гостевая демонстрация (удалена)

Предыдущий вариант — гостевые комнаты без регистрации на 15 минут (`/demo`, `DEMO_*`) — заменён ознакомительным уроком. Миграция `0008_demo.sql` оставлена без изменений (она уже опубликована); её таблицы удаляет `0009_trial_lesson.sql`. Настройки `DEMO_*` больше не читаются.
